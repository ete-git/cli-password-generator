
# パスワードジェネレーター README

## 概要
指定した文字数や文字種を基に、ランダムなパスワードを生成するプログラムです。

また、パスワードを保存したtxtファイルを安全に管理するための暗号化及び復号化の機能もあります。


## １. ファイル構成
* `main_menu.py`：パスワードを生成及び復号、暗号化を実行するプログラム。***※使用の際はこれを実行。***

* `pass_gen.py`：パスワードを生成するためのプログラム。

* `decrypt.py`：txtファイルの復号化をするプログラム。

* `ebcrypt.py`：txtファイルの暗号化をするプログラム

* `enter.py`：入力に関する関数モジュール。

* `generar.py`：パスワードを生成させる関数モジュール。

* `file_proc.py`：ファイル処理に関する関数モジュール。

* `passwd.txt`：生成されたパスワードが書き込まれているテキストファイル。***書き込みをすると追加されます。***

* `pass.key`：`passwd.txt`を復号化するためのキーファイル。***暗号化をすると追加されます。***


## ２. インストール
暗号化に必要なライブラリをターミナルからインストールします。
```bash
pip install cryptography    
```


## ３. 使い方

### 3.1.メインメニュー
`main_menu.py`を実行すると最初にメニューが開きます。

実行したいメニュー番号を入力します。
```
---- メニュー番号 ----
1. パスワード生成
2. ファイルの復号化
3. ファイルの暗号化
4. 終了
----------------------
メニュー番号を入力してください。(1~4)：
```
パスワードを生成する際は `1`。ファイルの復号及び暗号化は `2`,`3` を入力します。

また `[Ctrl]`+`[C]` の入力でメインメニューに戻ったりプログラムを終了させることができます。

## ４. パスワード生成
`main_menu.py`で `1` を入力した際に実行され、パスワードを生成を行います。

任意でtxtファイルの生成や暗号化も行うこともできます。

### 4.1.パスワードの文字数を指定


# パスワードジェネレーター (README)

**プレビュー表示を推奨します。**

簡潔な概要:
- 指定した文字数・文字種に従ってランダムなパスワードを生成するCLIプログラムです。
- 生成したパスワードを `passwd.txt` に書き込み、Fernet（cryptography）で暗号化／復号化できます。

## 1. 注意（重要）
- このリポジトリの実行エントリは `_main_menu.py` です。README内で `main_menu.py` と記載されている箇所は `_main_menu.py` を実行してください。
- また、暗号化モジュール名は `encrypt.py` です（README内の `ebcrypt.py` 表記は誤記です）。

## 2. ファイル構成（主要）
- `_main_menu.py`: メインメニュー（実行エントリ）。実行例: `python _main_menu.py`
- `pass_gen.py`: パスワード生成の上位制御（CLI ロジック）
- `generar.py`: パスワードをランダム生成する関数を定義
- `enter.py`: ユーザー入力関連のヘルパー（数値・y/n・パス入力）
- `file_proc.py`: `passwd.txt` 書き込み、暗号化・復号化の実装（cryptography.Fernet を使用）
- `encrypt.py`: 暗号化用CLIラッパー（`file_proc.pass_lock_alt` を利用）
- `decrypt.py`: 復号化用CLIラッパー（`file_proc.pass_unlock` を利用）

※ `passwd.txt` と `pass.key` は実行時に生成／上書きされます（リポジトリには含まれていません）。

## 3. 推奨セットアップ（初めての人向け）

```powershell
python -m venv .venv
```

## 4. 実行方法
カレントディレクトリをこのプロジェクトルートにした上で実行してください。

```bash
python _main_menu.py
```

実行後、メニューで操作を選択します。

メニュー例:
```
---- メニュー番号 ----
1. パスワード生成
2. ファイルの復号化
3. ファイルの暗号化
4. 終了
----------------------
メニュー番号を入力してください。(1~4)：
```

Ctrl+C でメニューへ戻る、またはプログラムを終了できます（確認プロンプトが個別に出る場合があります）。

## 5. パスワード生成の使い方（概要）
- 文字数を 5〜20 の範囲で指定します。数字以外は受け付けません。
- 小文字/大文字/数字/記号 の各文字種について `y` / `n` で選択します。
- 最低1種類を有効にする必要があります。
- 確認後、生成→表示され、希望すれば `passwd.txt` に書き込み、さらに希望すれば暗号化（`pass.key` の生成）します。

出力ファイルはカレントディレクトリに保存されます。`passwd.txt` と `pass.key` が既に存在する場合、上書きされるため注意してください。

### サンプル表示
```
<<パスワード生成完了>>
生成したパスワード：I7Pry1gAl6
```

## 6. 復号化／暗号化（ファイル指定のフロー）
- 復号化: メニューで `2` を選択 → `pass.key` のパス（またはドラッグ＆ドロップ）を入力 → `passwd.txt` のパスを入力 → 確認後復号化を実行します。
- 暗号化: メニューで `3` を選択 → 復号済みの `passwd.txt` のパスを入力 → 確認後暗号化を実行します。

注意点:
- `pass.key` と `passwd.txt` はペアでなければ復号できません。別の `pass.key` を使うと復号に失敗します。
- 入力にドラッグ＆ドロップを使う場合、シェルがパスを引用符で渡すことがあります。余分な引用符や前後の空白があると `enter.input_path()` の単純文字列判定に影響するので、その場合は手動でパスを貼り付けてください。

## 7. 実装上の注意（技術的）
- 暗号に `cryptography.Fernet` を利用しています。鍵は `pass.key`（バイナリ）として出力されます。
- `file_proc.pass_lock` / `pass_lock_alt` はファイルを上書きします。重要なデータがある場合は事前にバックアップしてください。
- `enter.input_path()` は与えられた入力文字列に期待するファイル名が含まれるかを確認する簡易チェックを行います。より堅牢にするには `.strip()` で余分な引用符や空白を取り除く実装を推奨します。
- pass.keyとpasswd.txtのペアが異なると正しく復号されません。※更新日時を確認
