# パスワードジェネレーター

指定した文字数と文字種からランダムなパスワードを生成する、Python製のCLIツールです。生成したパスワードはテキストファイルに保存でき、`cryptography` の Fernet を使って暗号化・復号化できます。

> **注意:** 本プロジェクトは学習・ポートフォリオ用の簡易ツールです。本番環境のパスワード管理には使用しないでください。生成される `pass.key` は、暗号化したファイルの復号に必要な重要な鍵です。

## 主な機能

- 5〜20文字のパスワード生成
- 小文字・大文字・数字・記号の使用有無の指定
- 生成したパスワードの `passwd.txt` への保存
- `cryptography.fernet.Fernet` によるファイルの暗号化・復号化
- メニュー形式の対話型CLI

## 必要な環境

- Python 3.8以上を推奨
- `cryptography`

## セットアップ

このREADMEと同じディレクトリで、仮想環境を作成して依存ライブラリをインストールします。

### Windows PowerShell

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
python -m pip install -r requirements.txt
```

PowerShellの実行ポリシーによって仮想環境を有効化できない場合は、仮想環境のPythonを直接使用できます。

```powershell
.\.venv\Scripts\python.exe -m pip install -r requirements.txt
```

### macOS / Linux

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## 実行方法

READMEと同じディレクトリで、次のコマンドを実行します。

```bash
python _main_menu.py
```

Windowsで仮想環境のPythonを直接指定する場合は、次のように実行します。

```powershell
.\.venv\Scripts\python.exe _main_menu.py
```

起動すると、次のメニューが表示されます。

```text
---- メニュー番号 ----
1. パスワード生成
2. ファイルの復号化
3. ファイルの暗号化
4. 終了
----------------------
```

## 使い方

### パスワードを生成する

1. メニューで `1` を入力します。
2. パスワードの長さを5〜20の範囲で入力します。
3. 小文字・大文字・数字・記号について、含める場合は `y`、含めない場合は `n` を入力します。
4. 内容を確認して `y` を入力すると、パスワードが生成されます。
5. 必要に応じて `passwd.txt` への保存と暗号化を選択します。

少なくとも1種類の文字を有効にする必要があります。`passwd.txt` に保存した場合、ファイルはカレントディレクトリに作成されます。

### ファイルを復号化する

1. メニューで `2` を入力します。
2. `pass.key` のパスを入力します。
3. 暗号化された `passwd.txt` のパスを入力します。
4. 確認で `y` を入力すると、`passwd.txt` が復号化されます。

ファイルはドラッグ＆ドロップでも指定できます。`pass.key` と `passwd.txt` は、暗号化時に作成された同じペアを使用してください。

### ファイルを暗号化する

1. メニューで `3` を入力します。
2. 復号済みの `passwd.txt` のパスを入力します。
3. 確認で `y` を入力すると、ファイルが暗号化されます。

暗号化すると、`pass.key` が新しく作成されます。既存の暗号化ファイルを復号する必要がある場合は、対応する古い鍵を別の場所に保管してください。

### 終了・中断する

メニューで `4` を入力すると終了します。`Ctrl+C` を入力すると、実行中の処理を中断してメニューへ戻るか、プログラムを終了します。

## 生成されるファイル

| ファイル | 説明 | Git管理 |
| --- | --- | --- |
| `passwd.txt` | パスワードを保存するファイル。暗号化時は暗号文で上書きされます。 | 対象外 |
| `pass.key` | `passwd.txt` の暗号化・復号化に使用する鍵。 | 対象外 |

`passwd.txt` と `pass.key` は実行時に作成され、`.gitignore` によってGitの管理対象外になっています。これらのファイルを削除または上書きすると、保存内容を復元できない場合があります。

## ファイル構成

| ファイル | 役割 |
| --- | --- |
| `_main_menu.py` | メインメニューとプログラムのエントリポイント |
| `pass_gen.py` | パスワード生成処理のCLI制御 |
| `generar.py` | パスワード生成関数 |
| `enter.py` | 数値・`y/n`・ファイルパスの入力処理 |
| `file_proc.py` | ファイルへの書き込み、暗号化、復号化 |
| `encrypt.py` | ファイル暗号化処理のCLI制御 |
| `decrypt.py` | ファイル復号化処理のCLI制御 |
| `requirements.txt` | Pythonの依存ライブラリ |
| `.gitignore` | 生成ファイルやキャッシュの除外設定 |
| `LICENSE` | MITライセンス |
